# 한국 시장에서 논문 방법론 검증

Shu·Yu·Mulvey의 [JM–XGBoost 논문 v2](https://arxiv.org/html/2406.09578v2)를 국내 자료에 적용한다. 원문과 동일한 11년 학습·5년 순차 검증·반기 재학습을 유지한다. 미국 원문 지수의 수치 재현과 구분한다. 성과를 계산하기 전에 `configs/korea.json`에 자산·기간·선택 기준·비용·민감도 분석을 고정했다.

## 데이터와 자산

| 자산 | 자료 | 수익률 정의 |
| --- | --- | --- |
| KOSPI·KOSDAQ | 네이버 일별 지수 | 가격수익률, 배당 제외 |
| 채권 3개월–1년 | KIS BC001056 | 총수익지수 |
| 채권 1–2년 | KIS BC001057 | 총수익지수 |
| 채권 2–3년 | KIS BC001058 | 총수익지수 |
| 채권 3–5년 | KIS BC001059 | 총수익지수 |
| 채권 5년 초과 | KIS BC001060 | 총수익지수 |
| 미국달러 | ECOS 731Y001 / 0000001 | 원화 기준 현물환율 변화, 달러이자 제외 |
| 대기자금 | ECOS CD91일 | 신호일 이전 연율 금리/100/252의 모형 계정 |

채권은 혼합 채권시장의 만기 구간이다. 국채·은행채·회사채를 별도 보유하는 구성이 아니며, 구간 사이의 높은 상관이 제약이다. CD 대기자금도 무위험 증권의 실제 투자 총수익으로 부르지 않는다. 주식 배당을 제외했으므로 전체를 총수익률 패널이나 ETF 실현 성과로 표현하지 않는다.

원천: [네이버 금융](https://finance.naver.com/), [KIS 종가지수](https://www.bond.co.kr/conts/10050), [한경·KIS 지수 정의](https://datacenter.hankyung.com/kis-bond), [한국은행 ECOS](https://ecos.bok.or.kr/), [FRED VIX](https://fred.stlouisfed.org/series/VIXCLS).

처음 조사한 한경·KIS 장기 섹터 차트에는 XKRX 거래일 213개가 누락되어 있었다. 일부 날짜에는 음수·0에 가까운 수치가 지수값 열에 들어 있는 등 명백한 이상치도 있었다. Yahoo 주식 지수에는 휴장일 행과 실제 거래일 누락이 있었다. 성과 적합 전에 이를 확인하고 네이버 주식과 KIS 직접 만기별 지수로 바꿨다. 빈 거래일을 보간하거나 자산 간 공통 날짜만 남기지 않는다. 네이버 두 지수의 6,109개 날짜는 독립 XKRX 달력과 전부 일치한다.

KIS 원천은 날짜별로 수집하고 지수코드·이름을 확인한다. 두 날짜가 달력상 바로 이어질 때에는 지수값의 변화율과 원천이 별도로 발표한 일별 수익률이 공개 반올림 범위 안에서 맞는지 검사한다. 종합지수 BMM01은 한경 장기계열과 대조하고, 99% 이상이0.011 지수포인트 안에서 일치해야 통과한다. 보조계열의 모든 불일치는 입력 검증 기록에 남기며 기본 KIS 값을 보조계열 값으로 바꾸지 않는다. 이 교차 대조는 공급자 자체의 과거자료 정확성을 독립적으로 증명하는 절차는 아니다.

KIS 가격의 공개 정밀도는 소수 둘째 자리다. 매우 작은 단기채 변동에는 반올림 영향이 있다. 조회 시점의 과거 제공 이력이며, 과거 구성종목·평가치의 모든 수정 빈티지를 복원했다고 주장하지 않는다.

## 학습과 평가

| 단계 | 기간 |
| --- | --- |
| 원자료·지표 준비 | 2001년부터 |
| 최초 11년 학습 | 2002.07–2013.06 |
| 최초 5년 순차 검증 | 2013.07–2018.06 |
| 최종 평가 | 2018.07–2025.09, 87개월 |
| 재학습 | 매년 1월·7월, 직전 11년 |
| 벌점 재선택 | 매 재학습일, 이미 생성된 직전 5년 순차 예측 |

25개 반기 × 8자산 = 200개 작업, λ 8개로 JM 1,600회 적합을 계획했다. 각 JM은 2상태·초기화10회다. 최초 11년을 확보할 때까지 지표 준비기간을 따로 둔다. 나쁜 결과를 이유로 5년·3년으로 줄이지 않는다.

JM 입력은 지수별 수익률 피처8개다. 원문의 국채·종합채권과 국내 혼합채권 만기구간이 정확히 대응하지 않으므로 국내 주 실험에서는 모든 자산에 같은8개를 적용한다. 분류기는 수익률8개와 시장5개를 쓴다. 시장 피처는 한국 3년 금리 변화, 10−3년 스프레드와 그 변화, 미국 VIX 변화, KOSPI/KIS 종합채권의252일 상관이다. VKOSPI를 긴 역사로 합성하지 않는다.

금리·VIX는 신호일보다 날짜가 엄격히 앞선 관측만 사용한다. 학습용 `X[t] → JM[t+1]`의 목표일은 훈련 종료일을 넘을 수 없다. JM 라벨·피처 표준화·조건부 평균을 훈련 안에서 계산한다. 미래자료를 바꿔도 기존 훈련 라벨과 최초 예측이 변하지 않는지 검사한다.

자료 수집 중 전체 ECOS 달력을 먼저 검사하면서 2017년 추석 휴장 뒤 첫 거래일인 10월 10일에 직전 관측일 9월 29일이 달력상 11일 전이라는 점을 확인했다. 최초의 일률적인 10일 경과 검사는 실제 결측이 없는 이 날짜를 잘못 거부했다. 한국 성과 적합 전에, 10일을 넘겨도 관측일이 바로 직전 XKRX 거래일에 도달한 경우에만 휴장 예외를 허용하도록 고쳤다. 사용한 관측일·직전 거래일·경과 일수를 입력 기록에 남긴다. 거래가 열린 동안 오래된 자료가 계속 유지되는 경우는 여전히 거부하며, 당일·미래 관측을 가져오거나 값을 보간하지 않는다.

XGBoost 2.1.4의 깊이6·100트리·학습률0.3과 로지스틱 C=1을 고정한다. λ는0 및0.1–100의 양의 로그 간격7개다. 원문은 정확한 그리드 개수를 공개하지 않았으므로 이 개수를 저자의 확정값으로 부르지 않는다.

## 두 비교 경로

1. **논문형 경로:** XGB의 검증기간 순비용 0/1 스위칭 샤프를 최대화한다. 초기5년에 λ와 평활 반감기0·2·4·8을 함께 고른 뒤, 평활은 고정하고 이후 λ만 다시 고른다. JM 단독은 평활0으로 별도 기록한다.
2. **동일 조건 비교:** LR·XGB의 검증 샤프 평균으로 공통 λ를 고른다. JM·LR·XGB는 같은 라벨·조건부 평균·반감기4·배분 규칙을 쓴다. 원문보다 XGB의 선택상 이점을 줄여 분류기의 추가 가치를 본다. 이 기준 역시 완전히 모형 독립적인 선택 기준은 아니다.

사전 주 비교는 동일 조건 MV의 XGB−LR 연율 CER 차이다. 샤프·최대낙폭·비용·회전율·위험자산 노출과 자산별 예측수익 IC를 함께 보고한다. CER 위험회피계수5, 대응 블록 재표집2,000회, 블록21·63거래일이다. 고정된 예측에 조건부인 구간이며 모형 재학습·다중 비교 불확실성을 모두 해소하지 않는다. JM 및 다른 배분 방식 비교는 보조 결과다.

한국의 개별 모형 성과를 보기 전에 설계를 고정했지만, 기존 미국 ETF 결과를 확인한 뒤 시장과 자산을 바꾼 후속 연구다. 전향적으로 확보한 완전 미사용 표본의 확증 실험으로 부르지 않는다. 연율 수치는252거래일 기준이며 실제 한국의 연간 거래일 수와 차이가 있다.

## 배분과 거래비용

MV·최소분산·동일비중·대기자금의 기본 계정과 국면 계정을 비교한다. 자산별40% 상한, 공매도·레버리지 금지, 일별 결정, 편도5bp를 적용한다. 비용은 위험자산 거래액에 부과하고 대기자금 계정의 이전 비용은0으로 둔다. 매번 비용 차감 뒤 NAV와 거래액을 함께 풀어 자금이 보존되도록 한다.

상승 국면이2개 이하이면 현금으로 전환한다. 이는 원문의 `3/12=25%`를 `2/8=25%`로 옮긴 것이다. 자산을8개로 줄이고도 원문의 숫자3을 그대로 쓰면 현금 전환 기준이 달라진다. 국면 MV의 위험회피계수10·거래비용 벌점1, 기본 MV 위험회피계수5·거래 벌점0을 사용한다. 하락 평균은−10bp 이하로 제한한다.

기본 실행 규약은 신호종가에서 다음종가까지의 지수 수익이다. 실제 같은 종가에 신호 산출과 체결이 모두 가능하다는 뜻이 아니다. 추가1거래일 지연을 함께 계산한다. 비용0·10·20bp와 강제 현금 전환 해제를 추가하고, 결과를 본 뒤 가장 좋은 조건만 주 실험으로 올리지 않는다. 전체31개 계정이다.

공개되지 않은 EWM·클리핑·그리드·일수·정확한 체결 규약은 명시적인 구현 선택이다. 실제 슬리피지·세금·지수 복제비용을 모두 반영한 운용 성과로 해석하지 않는다.

## 실행과 검증

```powershell
npm ci
uv sync --frozen
npm run typecheck
npx tsx src/harness.ts
npx tsx src/korea_harness.ts
npx tsx src/korea_pipeline.ts
```

파이프라인은 자료 수집→누수·계정 테스트→입력/코드 고정→모델 적합→배분→독립 원장 재계산→한국어8개 섹션 보고서를 이어서 실행한다. 요청 제한을 만나면 대기하고 속도를 낮춘다. 원 응답과 해시를 보관하며 중단 후 캐시를 재사용한다. 로컬 진행 상태는 `data/private/korea/pipeline.json`, 완료 결과는 `results/korea/README.md`다.

개별 단계는 `npx tsx src/korea.ts acquire|prepare|fit|allocate|verify`로 실행한다. 금융 실험의 `prepare`는 전체 자료가 없는 상태에서 실행되지 않으며, 실제 성과를 합성 테스트 자료로 채우지 않는다. 입력이 바뀌면 고정 기록과 캐시도 검증한다.

기존 글로벌 ETF 실험은 별도 보관한다. 국내 결과가 나오기 전에 기존 성과표의 제목만 국내 연구로 바꾸지 않는다. 원문 미국 지수의 1991–2023년 실험은 원자료가 없어 실행하지 않았다.
