# 실험 설계와 계산 규칙

이 저장소는 [Shu·Yu·Mulvey의 방법](https://arxiv.org/html/2406.09578v2)을 12개 ETF에 적용한다. 설계의 기준 파일은 [protocol.json](../configs/protocol.json)이며, 동일자료 재현이라고 부르지 않는다. 이전 연구 결과와 역사적 시장을 알고 설계한 후속 연구다. 현재 샘플의 성과를 아직 보지 않았다는 사실만으로 전향적 미사용 표본이 되지는 않는다.

## 순차 학습과 선택

각 자산에 별도의 2상태 Jump Model(JM)을 학습한다. 강세 상태는 학습창의 누적 초과수익이 높은 상태로 정렬한다. JM은 수익률 기반 8개 피처를 사용하되 AGG·TLT·GLD에서는 로그 하방편차 2개를 제외한다. 시장 피처는 JM에 넣지 않는다.

수익 피처는 DGS3MO를 252일로 나눈 일별 금리를 차감한 초과수익으로 만든다. 평균 반감기 5·10·21일, 하방편차 로그 반감기 5·21일, Sortino형 평균/하방편차 비율 반감기 5·10·21일이다. EWM은 `adjust=False`, 최소 63개 유효 관측으로 계산한다. 편차의 분모 하한은 1e-12다.

LR·XGB는 8개 수익 피처와 다음 5개 시장 피처를 받는다. DGS2 차분 EWM 21일, T10Y2Y EWM 10일, T10Y2Y 차분 EWM 21일, VIX 로그차분 EWM 63일, SPY–AGG 252거래일 수익률 상관이다. FRED는 날짜가 신호일보다 엄격히 이전인 최신 유효값을 사용한다. 10일을 넘는 오래된 값은 허용하지 않는다.

JM·분류기 스케일러는 각각 그 학습 자료로만 적합한다. 목표는 `X[t] -> JM 학습 라벨[t+1]`이며 마지막 학습일의 다음 라벨은 제외한다. 학습창의 JM 라벨은 창 내부 전체 경로를 사용하지만 창 이후 자료는 쓰지 않는다. 평가용 라벨은 고정된 JM의 온라인 필터 값이다. 이 값은 실제 경제 상태의 정답이 아니므로 예측 지표는 보조 진단이다.

1·7월 첫 거래일의 전 거래일 종가에 재학습한다. 이후 6개월 매일 전일 종가 피처로 예측한다. 벌점 후보는 0·0.1·1·10·100, 초기화 10회다. 정확한 논문 그리드가 공개되지 않아 이 그리드를 구현 규칙으로 고정했다. LR은 C=1·lbfgs·max_iter=2000, XGB는 버전 2.1.4의 100트리·깊이6·학습률0.3·단일 스레드다. 나머지 설정은 잠긴 버전의 기본값이다. 단일 클래스 창은 Laplace 빈도 확률을 사용한다. 일별 표본을 동일 가중하며 클래스/월별 재가중은 하지 않는다.

검증은 그 시점 이전 반기 모델들이 생성했던 일별 예측을 이어 붙인다. 현재 모델을 검증창에 소급 적용하지 않는다. 각 후보 확률의 평활은 검증 시작 이후 인과적으로 이어지며, 모델 교체 때 초기화하지 않는다. 각 검증창에서 0/1 계정은 BIL 100%로 새로 시작해 다음 시가에 ETF 또는 BIL로 전환한다. 검증창 마지막 수익률은 재학습일 종가까지다. 거래비용 차감 일별 수익률에서 실제 BIL 수익률을 차감한 샤프를 사용한다.

검증창의 시작은 반기 경계일(1월1일·7월1일)에서 검증 연수를 뺀 날 이상인 첫 거래일이다. 마지막 거래일에서 달력 연수를 빼면 주말·휴일 탓에 이전 반기의 날짜가 섞일 수 있으므로 반기 경계로 정렬한다.

논문형 경로는 XGB 검증 샤프로 벌점을 고른다. 첫 평가 반기에는 평활 반감기 0·2·4·8일과 벌점을 함께 고르고, 이후 평활은 고정하고 벌점만 갱신한다. 동률이면 짧은 평활, 작은 벌점을 우선한다. JM 유지 대조는 이 벌점을 공유하며 평활하지 않는다.

분류기 통제 경로는 LR·XGB 검증 샤프의 평균으로 벌점 하나를 골라 네 모델이 공유한다. 평활은 모두 4일이다. 이는 원문의 튜닝 규칙을 바꾼 통제 실험이며, 특정 분류기에 독점적으로 최적화한 라벨을 피하려는 설계다. 두 모델에 완전히 독립적인 벌점 선택은 아니다. 빈도 기준은 다음 라벨의 Laplace 학습 빈도, JM 유지는 신호일 온라인 상태, LR·XGB는 같은 13개 피처를 사용한다.

## 배분

강세 확률 ≥0.5를 강세로 판단한다. 국면 배분은 12개 중 강세가 3개 이하면 전액 BIL이다. 나머지 경우 다음 일별 목적함수를 최대화한다.

`w'μ − γrisk w'Σw − γtrade × c × ||w − wprev||₁`

위험자산 비중은 0 이상 40% 이하, 합계는 1 이하이며 잔여는 BIL이다. 거래벌점에는 위험자산 12개 다리만 포함하지만, 실제 거래비용에는 BIL을 포함한 13개 다리를 모두 넣는다. `wprev`는 신호일 종가 보유 비중이다. 모든 목적항에 같은 252를 곱해 수치 조건을 개선하며 상대 비율은 바꾸지 않는다. CVXPY–OSQP 허용오차는 1e-8, 최종 제약 확인 허용오차는 1e-7이다. 허용오차 내 미세 음수·초과만 투영한다.

| 배분 | 기대 초과수익 μ | γrisk | γtrade |
| --- | --- | ---: | ---: |
| 기본 MV | 과거 일별 초과수익 EWM, 반감기1260일 | 5 | 0 |
| 기본 MinVar | 모든 자산 일별10bp | 10 | 0 |
| 국면 MV | 학습창 동일 국면 평균, 약세는 min(평균, −10bp) | 10 | 1 |
| 국면 MinVar | 강세10bp, 약세0 | 10 | 1 |
| 기본 EW | 12개에 1/12 | 해당 없음 | 해당 없음 |
| 국면 EW | 강세 자산에 동일가중 | 해당 없음 | 해당 없음 |

약세 평균의 cap 문구는 상한으로 구현했다. 원문 저자의 코드상 해석을 확인하지 못했으며 본 구현의 명시적 선택이다. MinVar 기본 10bp, 공분산의 전체 사용 가능 역사·가중치 정규화·표본 편향 보정도 구현 규칙이다. 자산 간 음의 공분산과 거래벌점 때문에 기대수익이 0 이하인 개별 자산이 최적화에서 완전히 배제된다고 보장하지 않는다.

공분산은 12개 일별 초과수익을 모두 관측한 날부터 신호일까지, 반감기252일 EWM을 정규화하고 불편 보정한다. 최소252일을 요구한다. 통제 비교의 네 모델은 같은 μ 추정치·Σ·γ·제약·현금 규칙을 사용하고 강세 신호만 다르다. SPY/AGG 60/40은 일별 리밸런싱 참고 기준이며 개별40% 상한의 예외다.

## 체결과 성과

시가·종가 조정계수가 같은 일별 자료로 전일 종가→당일 시가의 수익은 기존 보유분에, 시가→종가의 수익은 새 보유분에 귀속한다. 목표 비중은 시가를 읽기 전에 정한다. 시가에 거래 전 자산가치 벡터 H가 주어지면 `V + c Σ|wᵢV−Hᵢ| = ΣHᵢ`를 풀어 비용 차감 후 NAV V와 거래량을 정한다. 비용은 총 매수·매도 금액에 편도5bp다. 매수자산에서만 비용을 빼지 않으며 배당을 이중 가산하지 않는다.

모든 계정은 평가 직전 종가 BIL100%·NAV1에서 시작한다. 평가 종료일에 강제 청산하지 않는다. 공통 21개월 성과는 각 전체 계정의 당시 보유량을 이어받은 부분 구간 수익률이다. 원문 11/5 프로필만 2024년 시작 시 BIL100%이므로 첫날 조건이 다를 수 있다.

연환산은252일, 샤프는 일별 전략 수익률−BIL 수익률의 평균/표본표준편차, CAGR은 순수익 복리, MDD는 구간 시작 NAV1을 포함한다. CER는 `252 × [일별 순수익 평균 − (5/2) × 순수익 분산]`인 산술 근사이며 효용 모수5는 최적화 위험회피10과 별개다. 연 비용은 일별 전일 NAV 대비 수수료의 평균×252, 회전율은 양방향 거래총액/시가 NAV의 평균×252다.

XGB−LR의 주 추정량은 main·5bp의 연 CER 차이다. 날짜를 함께 재표집하는 원형 이동블록 부트스트랩2,000회, 블록21일·보조63일, 백분위95% 구간을 제공한다. 두 모델의 동시기 상관은 유지하지만 모델 재학습·튜닝·연구자 선택 불확실성은 포함하지 않는다. 민감도와 보조 지표에 다중검정 보정은 하지 않으며 결과를 보고 주 전략을 교체하지 않는다.
