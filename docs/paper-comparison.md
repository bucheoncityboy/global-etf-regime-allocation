# 원문과 구현의 대응

기준은 [Dynamic Asset Allocation with Asset-Specific Regime Forecasts](https://arxiv.org/html/2406.09578v2)이다. 원문의 주요 질문은 국면 예측을 배분에 넣었을 때 전체 시스템이 개선되는가다. 표4의 JM–XGB와 JM 비교는 시장 피처와 튜닝도 다르며, XGBoost와 로지스틱의 동일 조건 우위를 검증하지 않는다.

| 항목 | 원문 | 이번 구현 |
| --- | --- | --- |
| 자산 | Bloomberg의 12개 일별 USD 지수 | 12개 ETF 대용 자료 |
| 역사·평가 | 1991–2023 / 2007–2023 | 공통 피처2007.07 이후 / 주 평가2016–2025.09 |
| 학습·검증 | 11년 / 5년 | 주5년/3년, 보조7년/3년과11년/5년 |
| 현금 | 3개월 Treasury 금리 | 피처·평균은 DGS3MO, 실제 계정과 샤프는 BIL |
| 국면 | 자산별 2상태 JM | 동일 구조, 저자 jumpmodels 고정 커밋 |
| JM 피처 | 수익 기반8개, 일부 자산 DD 제외 | 동일 종류, AGG·TLT·GLD DD 제외 |
| 분류 피처 | 수익8개 + 시장5개 | LR·XGB 모두 동일13개, SPY–AGG 상관 |
| 목표 시점 | 다음 날 JM 라벨 | 거래일 달력으로 정확히 다음 라벨에 정렬 |
| 재학습 | 반기 | 1·7월 첫 거래일 직전 종가 |
| 튜닝 | 순차 검증 0/1 샤프, λ 범위0–100 | 5개 명시 후보; 논문형은 XGB, 통제는 LR·XGB 평균 |
| 평활 | 최초 검증에서0·2·4·8 선택 | 논문형 동일 선택 구조, 통제4일 고정 |
| XGBoost | 기본값, 정확한 버전 불명 | 2.1.4 기본 용량(100트리·깊이6·학습률0.3) |
| 평균·위험 | 국면별 평균 / EWM252일 공분산 | 명시적 동일 구조, 미공개 세부는 아래에 규정 |
| 배분 | MV·MinVar·EW, 강세≤3이면 현금 | 동일 형태 |
| 거래 | 편도5bp | 전일 종가 결정·다음 시가 체결, 양쪽 자산 비용 |
| 최적화 | Gurobi | CVXPY–OSQP |

공개되지 않은 정확한 벌점 격자·학습 피처 warmup·EWM 초기화·기본 MinVar 상수·공분산 역사 길이·약세 cap의 코드 해석을 임의로 “원문과 동일”이라고 주장하지 않는다. 이번 값은 프로토콜과 방법론에 고정했다.

장기국채는 부록의 SPTL 대신 TLT, 회사채는 SPBO 대신 LQD다. SPY도 부록의 IVV와 다른 ETF다. 이는 이력 확보를 위한 자산군 대용이며 원문 지수를 합성하거나 상장 이전 가격을 소급 생성하지 않는다. 원문과의 차이가 남는 범위에서는 성과 방향만 대조한다.

이번 통제 비교는 동일한 JM 라벨과 배분 아래 LR·XGB의 차이를 다룬다. 과거 경제4국면 실험은 가져오지 않았다. 자산별 국면 예측과 분류기의 역할을 먼저 검증하는 범위다. 이 저장소의 결과가 좋아지더라도 원문 전체 재현이나 XGBoost의 일반적 우위를 뜻하지 않는다.
