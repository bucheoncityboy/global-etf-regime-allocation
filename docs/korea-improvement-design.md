# 한국 국면 배분 개선 실험

기존 한국 실험의 성과를 확인한 뒤 설계한 탐색 연구다. 기존 `results/korea` 및 원래 학습·원자료는 그대로 보존한다. 이 실험은 모델을 재학습하지 않고, 동일 조건 경로의 LR·XGB 예측으로 기대수익 변환과 매매 규칙만 비교한다. 원래의 11년 학습·5년 순차 검증·반기 재학습에서 만든 예측을 그대로 사용한다.

## 실행 전 고정하는 비교

| 단계 | 기대수익 변환 | 평균 배율 | 최소 거래 기준 |
| --- | --- | ---: | ---: |
| hard | 기존 50% 국면 판단 | 1 | 0 |
| probability | 국면 확률로 두 조건부 평균 가중 | 1 | 0 |
| shrink | 확률 가중 | 0.5 | 0 |
| buffer | 확률 가중 | 0.5 | 위험자산 편도 합산 2% |

확률 가중은 `p0*mu0+(1-p0)*min(mu1,-0.001)`이다. 첫 변경에서 확률 사용의 효과만 보기 위해 기존 하락 평균 상한을 유지한다. 0.5 축소율과 2% 거래 기준은 성과를 보기 전에 하나씩 고정하며 탐색·최적화하지 않는다.

거래 기준은 최적화가 제안한 위험자산 비중과 실행 직전 평가액 기준 비중의 절대차 합이다. 2% 미만이면 실행 직전의 모든 비중을 유지한다. 기존 전체 현금 전환 조건과 자산별 40% 한도 위반 교정은 이 완충 규칙보다 우선한다. 완충은 제안 비중에만 적용하며 직전 목표 비중을 반복해서 리밸런싱하지 않는다.

상승 국면 2개 이하이면 현금으로 전환하는 기존 규칙, 공분산, 비용 벌점, 위험회피계수10, 자산별40% 상한, 공매도·레버리지 금지는 유지한다. 확률 가중 뒤에도 전체 현금 전환은 이산적이므로 모든 불연속성이 제거되는 것은 아니다.

4단계 × LR·XGB × 추가 지연0·1 = 16계정이다. 기본 MV·최소분산·동일가중·현금을 두 지연 조건에서 각각 계산한 8계정을 더해 총24계정을 공개한다. 비용은 모든 계정에 위험자산 거래액의 편도5bp다. 같은 예측에 같은 변환을 적용해 분류기 차이와 배분 차이를 구분한다.

추가 지연1은 평가일의 두 거래일 전까지 알려진 예측·평균·공분산을 사용한다. 실행일의 실제 평가액과 보유 비중은 거래 시점에 알 수 있으므로 그대로 반영한다. 첫 거래일은 지연1 계정 모두 현금으로 시작해 기존 지연 계정과 맞춘다. 기본 실행은 여전히 지수 종가 연구 규약이며 실제 ETF 체결을 검증하지 않는다.

## 판정과 검증

평가기간은 2018.07.02–2025.09.30의 1,783거래일·87개월이다. 주 비교는 사전에 지정한 **buffer XGB−hard XGB, 편도5bp·추가 지연1**의 연율 CER 차이다. 인접 단계, 같은 단계 XGB−LR, buffer와 기본 최소분산 비교도 모두 공개한다. 성과가 가장 높은 단계를 주 비교로 승격하지 않는다. CER 위험회피계수5, 대응 블록 재표집2,000회, 블록21·63거래일을 사용하며 고정된 예측에 조건부인 보정 전 구간으로 표시한다.

원래 hard 계정 네 개(LR·XGB, 지연0·1)의 일별 NAV가 기존 공개 원장과 일치해야 한다. 모든24계정은 별도 brentq 자금보존 방정식으로 거래액·수수료·NAV를 재계산한다. 샤프는 현금 차감 일별 수익률로 다시 계산한다. 추가로 실제 보유 비중의 자산별 초과수익 기여와 비용 기여를 분해한다. 합성 테스트는 금융 성과 검증으로 인정하지 않는다.

실행 전 입력·기존 코드·새 코드의 해시를 고정한다. 기존 결과를 수정하지 않으며 원자료와 준비 패널은 비공개 경로에 둔다. 원자료가 없는 CI에서는 합성 시점·거래 테스트와 공개 결과의 해시·샤프·기존 계정 일치만 검사한다. 실제 가격으로 원장을 재계산하려면 기존 로컬 준비 패널이 필요하다.

이미 평가기간을 확인했으므로 양의 결과도 새로운 미사용 표본의 확증으로 부르지 않는다. 주식 배당·달러 이자 누락, 상관이 큰 채권 만기구간, CD 모형 계정 및 지수 체결 한계는 유지된다. 새 데이터 확보, 확률 보정, XGB 재학습·규제 조정은 이 배분 효과와 섞지 않고 후속 단계로 남긴다.

## 재현

```powershell
node --import tsx src/korea_improve_harness.ts
node --import tsx src/korea_improve.ts freeze
node --import tsx src/korea_improve.ts run
node --import tsx src/korea_improve.ts verify
node --import tsx src/korea_improve.ts verify-public
```

첫 실행의 고정 기록은 덮어쓰지 않는다. 중단 뒤에는 `run`으로 완료된 계정 캐시에서 재개한다. 결과는 `results/korea_improvement/README.md`, 캐시는 `data/private/korea/improvement/`에 저장한다.
